# Native toolbar

The optional toolbar provides workspace buttons, cropped-content controls and
access to original application menus. It targets macOS build 25G241.
Build with `python3 hook/toolbar/build.py --output /absolute/new/toolbar-build`.
Generated settings keep workspace actions and menu relocation off.

Clean installation, migration and fullscreen switching are not finished yet.
See [optional setup and disable commands](../../docs/INSTALL.md#optional-toolbar-and-application-menus).
The separate [appearance adapter](appearance/README.md) is inactive.
