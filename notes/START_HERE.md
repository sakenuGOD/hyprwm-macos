## 4. С чего начать после перезапуска

1. Проверить живое состояние:
   - демон работает (`/tmp/hyprwm.log` растёт);
   - движок стоит;
   - нет невидимых окон — команда `rescue` в сокет.
   Если демон не запущен — `hook/start.sh`.
2. Посмотреть последнюю запись `PROGRESS.md`. Если работа оборвалась посреди опыта с WindowServer —
   сначала убедиться, что всё откатилось.
3. native_hooks §8 шаги 1–2 — ПРОВЕРЕНЫ (PROGRESS 15:10–15:30: родной configure даёт рамку+содержимое в одном
   кадре; рамка нового окна до показа работает). Шаги 1–2 подключены к демону (`HYPRWM_NATIVE`, PROGRESS 15:40–16:00: configure через модуль,
   рамка нового окна = предсказанная плитка). Следующий — шаг 3: канал движок → модуль (`WSPostNotificationToConnection`)
   вместо Darwin notify — СДЕЛАН (HYPRWM15, PROGRESS 16:05); шаг 4 (минимумы, модуль v4) — СДЕЛАН.
   Дальше шаги 5–7 (свайп-флаг, подгоняемые слои, animationBehavior), затем beyond_bounds. Дальше §8 по порядку, параллельно — beyond_bounds.
4. Каждый шаг: сделать → проверить (`rec2`, журнал траектории, числа) → записать в `PROGRESS.md`.
